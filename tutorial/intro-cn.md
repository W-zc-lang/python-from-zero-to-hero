# Python 从入门到精通

> 一份写给初学者的、循序渐进的系统学习指南
>
> 覆盖：基础语法 · 数据类型 · 控制流 · 函数 · 面向对象 · 模块与包 · 文件操作 · 异常处理 · 常用标准库 · 网络爬虫 · 自动化办公
>
> 适合人群：零基础或有一点编程经验、希望系统掌握 Python 的读者。

## 本仓库是什么

这是一份**中英双语**（中文在上、英文在下对照）的 Python 系统教程，专为「从入门到精通」设计。全文共 **15 章 + 1 篇附录**，配备 **20 张手绘 SVG 示意图**，逐知识点讲解、配可运行代码示例，零基础也能读懂。

## 内容总览

- 第 1–2 章：为什么学 Python、环境搭建
- 第 3–5 章：基础语法、变量、数据类型（数字/字符串/列表/字典等）
- 第 6–7 章：条件与循环、函数
- 第 8–9 章：面向对象、模块与包
- 第 10–12 章：文件操作、异常处理、常用标准库
- 第 13 章：进阶与精通之路
- 第 14–15 章：网络爬虫、自动化办公（实战向）
- 附录：常见错误与调试、推荐资源

## 如何阅读

- 想一口气读完：直接看仓库首页的 `README.md`（即全文）。
- 想按章节阅读：打开 `chapters/` 目录，每章一个独立文件。
- 想离线收藏：到 **Releases** 下载打包好的完整压缩包（含全部章节与配图）。
