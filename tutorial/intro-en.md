# Python: From Beginner to Master

> A step-by-step, systematic learning guide written for beginners.
>
> Covering: basic syntax · data types · control flow · functions · object-oriented programming · modules and packages · file operations · exception handling · common standard libraries · web scraping · office automation.
>
> Who it's for: readers with no prior experience, or a little programming background, who want to master Python systematically.

## What this repository is

A **bilingual (中文 / English)** Python tutorial presented side-by-side (Chinese on top, English below). It is designed to take you **from beginner to master**. The full text contains **15 chapters + 1 appendix**, accompanied by **20 hand-drawn SVG diagrams**. Every concept is explained in plain language with runnable code examples — accessible even with zero background.

## Contents at a glance

- Ch. 1–2: Why Python, and setting up your environment
- Ch. 3–5: Basic syntax, variables, data types (numbers / strings / lists / dicts …)
- Ch. 6–7: Conditionals & loops, functions
- Ch. 8–9: Object-oriented programming, modules and packages
- Ch. 10–12: File operations, exception handling, common standard libraries
- Ch. 13: The path to advanced & proficient Python
- Ch. 14–15: Web scraping, office automation (hands-on)
- Appendix: Common errors, debugging, and recommended resources

## How to read

- Read it all at once: the repo homepage `README.md` **is** the full text.
- Read by chapter: open the `chapters/` folder — one standalone file per chapter.
- Download for offline use: grab the packaged bundle in **Releases** (all chapters + diagrams included).
